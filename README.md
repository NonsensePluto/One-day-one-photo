# One day one photo

Приложение, которое выводит пользователю случайную фотографию из онлайн галереи [Unsplash.com](https://unsplash.com).  

---

## Описание
На экран пользователю выводится картинка из Unsplash, пользователь может сохранить эту картинку в панель уведомлений и таким образом, кастомизировать панель. 
Чтобы убрать картинку с панели нужно нажать на соответствующую кнопку. Так же есть возможность перелистнуть картинку, в этом случае цвет фона меняется под цвет новой картинки, 
и изображение на экране плавно меняется.

---
## Технологии
- Язык программирования: **Kotlin**,
- Среда разработки: **AndroidStudio**,
- Работа с сетью: **Ktor**,
- Автоматический DI: **Hilt + Dagger**,
- Верстка экранов: **XML**,
- Работа с системой уведомлений: **Foreground Service**,
- Работа с изображениями: **Glide**,
- Архитектурные решения: **Clean Architecture + MVVM**.
